Architecture Overview

The TravelBuddy platform exposes a RESTful JSON API for mobile and web clients, automated workflows, and partner systems. All production API traffic is served over HTTPS with support for standard HTTP verbs, CORS authentication, and structured error responses.

Base URL: https://travelbuddy-backend-19l6.onrender.com Local Dev: http://localhost:4000 Content-Type: application/json

Authentication

Protected endpoints require a JSON Web Token (JWT) provided in the HTTP Authorization header using the Bearer schema:

Authorization: Bearer <YOUR_JWT_TOKEN>

Obtain a valid token by sending credentials to POST /api/auth/login or POST /api/auth/register. Tokens are cryptographically signed and encode the user's role and verified status.

Key REST Endpoints

POST /api/auth/login
Authenticates a user via email/phone and password. Returns JWT token, user roles, and profile information.
POST /api/postparcel/create
Creates a new parcel delivery order with origin, destination, parcel specifications, and proposed delivery fee. Requires Bearer authentication.
GET /api/postparcel/search
Searches public active parcel requests filtered by query parameters: from, to, and category.
POST /api/travelroutes/create
Travelers post their travel itinerary (origin, destination, departure date, luggage capacity).
POST /api/postparcel/:id/verify-otp
Validates the final delivery OTP provided by the receiver upon handover, instantly releasing held funds to the traveler's wallet.

Model Context Protocol (MCP)

TravelBuddy provides first-party Model Context Protocol (MCP) server support, allowing autonomous AI agents to query routes, calculate price estimates, and inspect platform status safely.

Discovery Endpoint: https://travalbuddy.web.app/.well-known/mcp
Transport Protocol: Server-Sent Events (SSE) & Streamable HTTP POST at https://travelbuddy-backend-19l6.onrender.com/mcp

Available MCP Tools

  • estimate_delivery_fee: Computes estimated fee based on distance, parcel weight, and delivery urgency.
  • search_travel_routes: Finds verified travelers traveling along specific routes.
  • get_parcel_status: Retrieves public tracking milestones for a specific order ID.
  • list_prohibited_items: Returns categories of prohibited and restricted cargo.
  • get_platform_info: Returns verified system operational status and capabilities.

Rate Limits & Security

All API endpoints enforce IP-based rate limiting to protect platform infrastructure:

  • Auth endpoints: 100 requests per 15-minute window.
  • Parcel & Route creation: 50 actions per 10-minute window.
  • Global API limit: 5,000 requests per 10-minute window.
